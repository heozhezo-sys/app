# HABITS

Habit fields: name, description, category, icon, frequency, target, unit, reminder and notes.

Frequency: daily, weekdays, weekends, selected days, weekly, monthly and custom.

Track completion events rather than only a current counter.

Show current streak, best streak, completion rate, missed days and history.

Allow pause, archive, edit and recovery after missed days.

The interface must be supportive, not punitive.

Offline logging is immediate and persists across app restarts.
