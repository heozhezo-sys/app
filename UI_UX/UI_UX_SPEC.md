# UI/UX SPEC

LifeOS is a premium native iOS-style app: calm, clear, fast and focused.

## Primary navigation
Today | Habits | Fitness | Library | Goals

## Interaction
Use native sheets, context menus, haptics, safe areas and large navigation titles.
Use progressive disclosure for advanced options.

## Every screen
Provide loading, empty, error and success states plus accessible labels.

## Visual hierarchy
Prioritize today's actions, progress and next steps. Do not fill every screen with metrics.

## Reader
The book reader is immersive and hides controls during reading. Tap the center to toggle controls. Swipe changes pages. Pinch zooms.

## Accessibility
Support Dynamic Type, VoiceOver labels, contrast, large touch targets and reduced motion.
